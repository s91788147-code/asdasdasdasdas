# Discord Ticket Bot + админка

Тикет-бот для Discord (discord.js v14) с веб-админкой (Express + EJS) и хранилищем SQLite.

## Возможности

**Бот**
- Панель с кнопкой «Создать тикет» или меню выбора типа обращения
- Форма (modal) с описанием проблемы при создании тикета
- Приватный канал для каждого тикета (автор + роль поддержки)
- Кнопки «Взять» и «Закрыть» в тикете
- Лимит открытых тикетов на пользователя
- Транскрипт `.txt` в канал логов при закрытии + уведомление автору в ЛС
- Слэш-команды:
  | Команда | Кто | Описание |
  |---|---|---|
  | `/setup [category] [support_role] [log_channel]` | админ | Настройка |
  | `/panel [channel]` | админ | Отправить панель |
  | `/close [reason]` | поддержка / автор | Закрыть тикет |
  | `/claim` | поддержка | Взять тикет |
  | `/add user`, `/remove user` | поддержка | Добавить/убрать участника |

**Админка** (`http://localhost:3000`)
- Вход по логину/паролю из `.env` (сессии, CSRF, защита от перебора)
- Дашборд: статистика, серверы, последние тикеты
- Список тикетов с поиском, фильтрами и пагинацией
- Просмотр переписки, ответ в тикет от имени бота, закрытие, скачивание транскрипта
- Настройки сервера: категория, роль поддержки, канал логов, тексты панели и приветствия, лимит
- Управление типами тикетов и отправка панели в любой канал

## Установка

1. Создайте приложение на <https://discord.com/developers/applications>, во вкладке **Bot**:
   - скопируйте токен;
   - включите **Server Members Intent** и **Message Content Intent**.
2. Пригласите бота (OAuth2 → URL Generator) со scope `bot` + `applications.commands` и правами:
   *Manage Channels, Manage Roles, View Channels, Send Messages, Embed Links, Attach Files, Read Message History*.
3. Установите и запустите:

```bash
npm install
cp .env.example .env   # заполните DISCORD_TOKEN, CLIENT_ID, ADMIN_PASSWORD, SESSION_SECRET
npm start
```

Слэш-команды регистрируются автоматически при старте (или вручную: `npm run deploy`).
Укажите `GUILD_ID`, чтобы команды появлялись на тестовом сервере сразу, а не через ~1 час.

4. На сервере выполните `/setup`, затем `/panel` — или сделайте то же самое в админке.

## Структура

```
src/
  index.js              точка входа (бот + веб)
  db.js                 SQLite: настройки, типы, тикеты, сообщения
  bot/
    client.js           обработчики событий и взаимодействий
    commands.js         определения слэш-команд
    deploy-commands.js  регистрация команд
    tickets.js          логика: панель, открытие/закрытие, транскрипты
  web/
    server.js           Express-админка
    views/              EJS-шаблоны
    public/style.css
```

> Для продакшена поставьте админку за HTTPS-прокси (nginx/Caddy) и задайте длинный `SESSION_SECRET`.
